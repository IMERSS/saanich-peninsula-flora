In Memory of Plants

W̱SÁNEĆ peoples have cared for these lands and waters since time immemorial.

The memory preserved here is much more limited: collected specimens, names written on lists, and observations shared through iNaturalist, reaching back to 1859.

Each record is a moment when someone stopped to take note of a plant.

Some plants are recorded often, some have appeared only in more recent years, while others have quietly disappeared from the record.
