# Correction of the Solow singularity for a single sighting in the analysis year

The extirpation probability (EP) map showed population 14 of *Persicaria maculosa* with EP = 1.00, though its one
sighting was made in 2026, the analysis year itself - see `EP1-Persicaria.jpg`. A population seen this year should
have EP = 0.

## Cause

The fault was a single wrong guard in the one-sighting branch of `bioreportr.solowBayesFactor`, in
`static/bioreportr/js/solow.js`:

```js
} else if (n === 1) {
    const lnRatio = Math.log(T / tn);
    B = lnRatio <= 0 ? 0 : 1 / lnRatio;
```

`T` is the length of the observation period (analysis year minus baseline year), and `tn` is the time of the last
sighting, measured from the baseline. Population 14 has one sighting, in 2026, which is also the analysis year. So
`tn = T`, `T/tn = 1`, and `ln(T/tn) = 0`.

- **The guard sent that case the wrong way.** It set the Bayes factor `B` to 0, which means the strongest possible
  evidence of extirpation. Then `pp = B/(1+B) = 0`, so EP = 1.
- **The correct value is the opposite.** For one sighting, Solow's factor is the limit of the general formula
  `(n−1)/((T/tn)^(n−1) − 1)` as `n` tends to 1, which is `1/ln(T/tn)`. As the last sighting approaches the end of the
  period, `ln(T/tn)` falls towards 0 and `B` grows without limit. A population seen this year should get EP = 0.
- **The branch for two or more sightings already handled this correctly.** When the last sighting is in the analysis
  year, its denominator is 0 and the code sets `B = ∞`, giving EP = 0.

So the singularity was only in the `n === 1` branch: its guard returned 0 where the other branch returns ∞.

The same guard also covers a last sighting *after* the analysis year (`tn > T`, so the log is negative), for instance
if the analysis year were ever set too early. Infinity is the right answer there too.

## Correction

The guard now returns infinity:

```js
B = lnRatio <= 0 ? Number.POSITIVE_INFINITY : 1 / lnRatio;
```

The other guard is unchanged. When `tn <= 0`, the last sighting fell in the baseline year or earlier, and `B = 0`
(EP = 1) is the correct limit there.

## The R copy

`solow_ep` in `scripts/apply_record_annotations.R` mirrors the JavaScript line for line, and had the same guard,
`if (ln_ratio <= 0) 0 else 1 / ln_ratio`. It is corrected in the same way, to `Inf`. The EPs it writes for annotated
taxa must be regenerated by rerunning the script. `scripts/prepare_summary.R` only reads `solow_EP` and doesn't
compute it.

The "Regional EP: 0" shown in the screenshot is the taxon's `solow_EP` from the summary data, not this code. It is
computed over all 27 records, so it isn't affected.

## Carrying the correction to the other projects

`solow.js` is shared framework code, so the correction must be carried to howe-sound-mapping-2026 with
`copyFrameworkOut.sh`, after a dry run with `-n`. The R script belongs to Saanich alone.
